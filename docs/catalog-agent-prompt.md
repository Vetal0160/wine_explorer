# Промт для агента с веб-поиском: винодельни и вина Молдовы

Скопируйте всё, что ниже линии, в агента (ChatGPT с поиском, Perplexity, Gemini
Deep Research и т.п.). Результат — два CSV-файла, которые проверяет и загружает
`python tool/catalog_sheet.py import <папка с CSV>`.

---

Ты — исследователь. Собери проверенные данные о винодельнях Республики Молдова и их винах для каталога в мобильном приложении. Результат — **два CSV-файла**: `wineries.csv` и `wines.csv`.

## Объём
- **25–30 виноделен**, которые производят вино в Молдове и либо принимают туристов, либо их вина широко продаются. Обязательно включи эти 7 (дополни по ним недостающие поля): Château Vartely, Château Purcari, Cricova, Mileștii Mici, Castel Mimi, Asconi, Et Cetera.
- **3–5 известных вин** у каждой винодельни — всего около 100 вин.
- Только **сухие тихие вина и игристые**. Полусухие, полусладкие, сладкие, десертные, креплёные и дивины (бренди) пропускай.

## Главное правило: не выдумывать
- Каждый факт — только из проверяемого источника: официальный сайт винодельни, её официальные соцсети, wineofmoldova.com, moldova.travel, крупные молдавские винные магазины (для цен).
- **Если не нашёл — оставь ячейку пустой.** Пустая ячейка лучше неправильной. Особенно это касается телефона, часов работы, цен, года основания и координат.
- В колонку `sources` каждой строки запиши ссылки, откуда взяты данные (через пробел).
- Сомнения и противоречия между источниками опиши в колонке `notes`.

## Формат CSV
- Кодировка UTF-8, разделитель — **запятая**, первая строка — заголовки **точно как ниже**, текст с запятыми — в двойных кавычках.
- Названия — **точно как на этикетке или официальном сайте, с румынскими буквами** (ă â î ș ț): «Fetească Neagră», «Mileștii Mici».
- Числа — с точкой: `46.5250`, `4.5`.

### wineries.csv
```
name,region,latitude,longitude,founded_year,address,phone,website,hours_ru,hours_ro,hours_en,has_tastings,tasting_price_lei,booking_required,description_ru,description_ro,description_en,image_url,sources,notes
```
| Колонка | Что писать |
|---|---|
| name | Название винодельни (обязательно) |
| region | Регион и село: `Ștefan Vodă · Purcari`, `Codru · Cricova` |
| latitude, longitude | Координаты винодельни или её центра для посетителей, 4+ знака после точки (обязательно). Широта 45.4–48.5, долгота 26.6–30.2 — иначе ошибка |
| founded_year | Год основания, если указан на официальном сайте |
| address | Адрес для посетителей |
| phone | Телефон для туристов/дегустаций в формате `+373 …` |
| website | Официальный сайт `https://…` |
| hours_ru / hours_ro / hours_en | Часы работы для посетителей, как опубликованы: `Пн–Сб 10:00–18:00` / `Lun–Sâm 10:00–18:00` / `Mon–Sat 10:00–18:00` |
| has_tastings | `да` или `нет` — только если сайт это прямо сообщает |
| tasting_price_lei | Минимальная цена дегустации в MDL, числом |
| booking_required | `да` / `нет` — нужна ли предварительная запись |
| description_ru / _ro / _en | 1–3 предложения о винодельне: история, чем известна, что посмотреть. **Своими словами, не копировать с сайтов.** Без рекламных превосходных степеней, которые нельзя проверить |
| image_url | **Оставь пустым** (фото добавим сами — авторское право) |
| sources | Ссылки на источники |
| notes | Что не удалось проверить |

### wines.csv
```
name,winery,type,grape_variety,vintage,rating,price_lei,description_ru,description_ro,description_en,image_url,sources,notes
```
| Колонка | Что писать |
|---|---|
| name | Название вина как на этикетке (обязательно), без названия винодельни в начале, если на этикетке его нет |
| winery | **Точно** как `name` в wineries.csv (обязательно) |
| type | Строго одно из: `red_dry`, `white_dry`, `rose_dry`, `sparkling` (обязательно) |
| grape_variety | Сорта через запятую, как на этикетке. Пиши так: Fetească Neagră, Rară Neagră, Fetească Albă, Fetească Regală, Viorica, Cabernet Sauvignon, Merlot, Pinot Noir, Chardonnay, Sauvignon Blanc (другие сорта — тоже можно) |
| vintage | Год урожая, который сейчас в продаже; `NV` — если без года |
| rating | **Оставь пустым** (оценки выставим сами) |
| price_lei | Типичная розничная цена в Молдове в MDL, числом, из магазина или магазина винодельни (ссылку — в sources). Не нашёл — пусто |
| description_ru / _ro / _en | 1–2 предложения о вкусе и аромате **своими словами** |
| image_url | **Оставь пустым** |
| sources | Ссылки на источники |
| notes | Сомнения |
